# TestData Library API Reference

This document outlines the public API for the `CompanyNamespace.TestData` library. The purpose of this library is to structure, store, and serialize hierarchical test data. A replacement plugin should implement the same public interfaces, classes, and behaviors described below.

The data is organized in a hierarchy:

  * A `DataFile` is the top-level container.
  * A `DataFile` contains one or more `DataGroup` objects.
  * A `DataGroup` contains one or more `DataSweep` objects.
  * A `DataSweep` contains one or more `DataRow` objects.
  * A `DataRow` contains the actual test measurements, which can be single key-value pairs (`ParameterValue`) or arrays of data (`DataArray`).

-----

## Core Interfaces

These interfaces define the primary contracts for manipulating the test data structure.

### IDataFile

The main container for the entire test data set.

```csharp
public interface IDataFile
{
    Header Header { get; set; }
    IDataGroup ActiveGroup { get; }
    IDataGroup NewGroup();
    void FinalizeGroup();
    void FinalizeFile(bool testPassed, double testTimeElapsedSeconds);
    void ToJSON(string filePath);
    void ToCSV(string filePath);
}
```

### IDataGroup

A logical grouping of test sweeps, often corresponding to a specific test condition or module.

```csharp
public interface IDataGroup
{
    IDataSweep ActiveSweep { get; }
    void AddGroupDetail(string detailName, string detailValue);
    IDataSweep NewSweep(Parameter sweepByParameter);
    void FinalizeSweep();
}
```

### IDataSweep

A collection of data rows, typically generated by sweeping a variable (e.g., frequency, power).

```csharp
public interface IDataSweep
{
    IDataRow ActiveRow { get; }
    string KickoutMessage { get; set; }
    IDataRow NewRow();
    void FinalizeRow();
}
```

### IDataRow

Represents a single measurement point or a collection of related measurements within a sweep.

```csharp
public interface IDataRow
{
    void AddParameterValue(ParameterValue pv);
    void AddParameterValue(Parameter parameter, object value);
    void AddParameterValues(List<ParameterValue> parameterValues);
    void AddArrayData(Parameter Parameter, List<double> doubles, Parameter linkParameter);
    Dictionary<Parameter, string> GetRowAsDictionary();
    List<ParameterValue> GetParameterValues();
    List<ParameterArrayGroup> GetParameterArrayGroups();
}
```

## Primary Data Structures

These are the concrete classes that make up the test data hierarchy.

### DataFile

The top-level class that manages data groups and file-level metadata.

```csharp
public class DataFile : IDataFile
{
    // Properties
    public Header Header { get; set; }
    public List<DataGroup> DataGroups { get; set; }
    public bool TestCompleted { get; set; }
    public IDataGroup ActiveGroup { get; }

    // Constructors
    public DataFile(Header header);

    // Methods
    public void FinalizeFile(bool testPassed, double testTimeElapsedSeconds);
    public void FinalizeGroup();
    public IDataGroup NewGroup();
    public void ToJSON(string filePath);
    public void ToCSV(string filePath);
}
```

### DataGroup

Manages a collection of `DataSweep` objects and group-level metadata.

```csharp
public class DataGroup : IDataGroup
{
    // Properties
    public int GroupID { get; }
    public List<DataSweep> DataSweeps { get; set; }
    public IDataSweep ActiveSweep { get; }
    public Dictionary<string, string> GroupDetails { get; set; }

    // Constructors
    public DataGroup(int groupID);
    public DataGroup(int groupID, Dictionary<string, string> groupDetails);

    // Methods
    public void AddGroupDetail(string detailName, string detailValue);
    public void FinalizeSweep();
    public List<ParameterValue> GetParameterValues();
    public SortedSet<Parameter> GetUniqueFields();
}
```

### DataSweep

Manages a collection of `DataRow` objects and sweep-level metadata.

```csharp
public class DataSweep : IDataSweep
{
    // Properties
    public int SweepID { get; }
    public List<DataRow> DataRows { get; set; }
    public IDataRow ActiveRow { get; }
    public Parameter SweepByParameter { get; set; }
    public string KickoutMessage { get; set; }

    // Constructors
    public DataSweep(int sweepID, Parameter sweepByParameter);

    // Methods
    public void FinalizeRow();
    public IDataRow NewRow();
    public List<ParameterValue> GetParameterValues();
    public SortedSet<Parameter> GetUniqueFields();
}
```

### DataRow

Manages a collection of `ParameterValue` and `DataArray` objects for a single data point.

```csharp
public class DataRow : IDataRow
{
    // Properties
    public int RowID { get; }

    // Constructors
    public DataRow(int rowID);

    // Methods
    public void AddArrayData(Parameter parameter, List<double> doubles, Parameter linkParameter);
    public void AddParameterValue(ParameterValue pv);
    public void AddParameterValue(Parameter parameter, object value);
    public void AddParameterValues(List<ParameterValue> parameterValues);
    public List<ParameterArrayGroup> GetParameterArrayGroups();
    public List<ParameterValue> GetParameterValues();
    public Dictionary<Parameter, string> GetRowAsDictionary();
    public ConcurrentSet<Parameter> GetUniqueFields();
}
```

### Header

Contains all metadata related to the test file, such as part number, serial number, and test results.

```csharp
public class Header
{
    // Properties
    public string PartNumber { get; set; }
    public string SerialNumber { get; set; }
    public string Testplan { get; set; }
    public Dictionary<string, string> CommentFields { get; set; }
    public DateTime Date { get; set; }
    public string OperatorName { get; set; }
    public string TestStand { get; set; }
    public string DataType { get; set; }
    public string GroupingIdentifier { get; set; }
    public string TraceCode { get; set; }
    public string ProductRev { get; set; }
    public string EvalStage { get; set; }
    public bool ResultPasses { get; }
    public double TestTimeSeconds { get; }
    public SortedSet<Parameter> UniqueFields { get; }

    // Constructors
    public Header(string partNumber, string serialNumber, string testplan, Dictionary<string, string> commentFields, string operatorName, string testStand);
    public Header(string partNumber, string serialNumber, string testplan, Dictionary<string, string> commentFields, string operatorName, string testStand, string dataType, string groupId, string traceCode, string productRev, string evalStage);

    // Methods
    public void AddCommentField(string parameter, string value);
    public void MarkAsComplete(bool testPassed, double testTimeElapsedSeconds);
}
```

## Supporting Data Types

These classes are used to define and store measurement data.

### Parameter

Represents the name and units of a measurement. It can be parsed from a string like `"Pout(dBm)"`.

```csharp
public class Parameter : IComparable<Parameter>, IEquatable<Parameter>
{
    // Properties
    public string Name { get; set; }
    public Unit Units { get; set; }

    // Constructors
    public Parameter(string parameterName, Unit units);
    public Parameter(string parameterName, UnitsType unitsType);
    public Parameter(string parameterNameWithUnits);

    // Methods
    public override string ToString();
}
```

### ParameterValue

Associates a `Parameter` with its measured `Value`.

```csharp
public class ParameterValue : IEquatable<ParameterValue>
{
    // Properties
    public Parameter Parameter { get; }
    public object Value { get; set; }
    public string Name { get; }
    public Unit Units { get; }

    // Constructors
    public ParameterValue(string parameterWithUnits, object value);
    public ParameterValue(string parameterName, Unit units, object value);
    public ParameterValue(Parameter parameter, object value);

    // Methods
    public string FormatValue();
}
```

### DataArray

Represents a list of `double` values associated with a specific `Parameter`. It can be linked to another parameter, such as an x-axis value.

```csharp
public class DataArray : IEquatable<DataArray>, IComparable<DataArray>
{
    // Properties
    public Parameter Parameter { get; set; }
    public List<double> Data { get; set; }
    public Parameter LinkParameter { get; set; }

    // Constructors
    public DataArray();
    public DataArray(Parameter parameter, List<double> data, Parameter linkedParameter);

    // Methods
    public string GetDataAsString(); // e.g., "[1.1,2.2,3.3]"
}
```

### ParameterArrayGroup

A helper class used to group multiple `DataArray` objects that share the same `LinkParameter` and length.

```csharp
public class ParameterArrayGroup
{
    // Properties
    public int GroupSize { get; }
    public List<DataArray> DataGroup { get; set; }
    public Parameter GroupByParameter { get; set; }

    // Constructors
    public ParameterArrayGroup();

    // Methods
    public void AddDataArray(DataArray dataArray);
}
```

```csharp
    public static Parameter Harmonic_dBm(int index);
    public static Parameter ACLR_Upper_dBc(int index);

```

### Configuration

A singleton class to manage global settings that affect data serialization.

```csharp
public class Configuration
{
    // Properties
    public static Configuration Instance { get; set; }
    public bool InsertNullRowBetweenSweeps;

    public Configuration();
}
```
